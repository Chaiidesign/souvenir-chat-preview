# Souvenir — Chat Preview

**Live preview → [chat-preview-standalone.vercel.app/chat-preview](https://chat-preview-standalone.vercel.app/chat-preview)**

Animation prototype for the Souvenir V2 individual chat experience. Shows how the message flow looks and feels before engineering builds it.

---

## What this shows

The control panel contains chat and output scenarios, including these reference cases:

| Mode | What happens |
|------|-------------|
| **Simple** | Routing → model chosen → text streams in → done |
| **Research** | Same, plus web sources load one by one → collapse → stream |
| **E1 Error** | Connector auth failure — inline in the response |
| **E2 Error** | Web search timeout — partial sources, then inline error |

Select **S18 · Output: Invoice PDF** for a fixed synthetic document scenario. It shows an in-chat artifact card, an embedded preview of the exact PDF file, and a download of that same file. The sample PDF was generated by the [Commerce Document Atlas invoice proof](https://github.com/Chaiidesign/commerce-document-atlas/blob/fix/fractional-cent-validation/design/INVOICE_ENGINE_PROOF.md) from invented test facts. This is a UI prototype: it does not invoke an AI model, generate a new file from the prompt, verify an operator's facts, or send an invoice. The PDF is committed as a static demo asset so preview and download use identical bytes.

## Running locally

```bash
npm install
npm run dev
```

Open [localhost:3000/chat-preview](http://localhost:3000/chat-preview)
